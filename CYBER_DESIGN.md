# Cyberfront: Browser-Based Cyberwarfare RTS

## Overview

Cyberfront transforms the OpenFront.io RTS engine into a **cyberwarfare game** where players battle for control of network infrastructure instead of geographical territories.

## Core Concepts

### Territories → Datacenters

Instead of claiming land, players claim **datacenters** on a network map:
- **AWS Global**: Cloud provider infrastructure
- **Azure Regions**: Enterprise cloud zones
- **Internet Backbone**: Core network hubs
- **Darknet**: Hidden network infrastructure
- **Corporate Networks**: Private enterprise segments

Each datacenter generates:
- **Bandwidth** - Network throughput (shared resource like gold)
- **Compute Power** - Processing capacity (like troops)
- **Intelligence** - Gathered data for special operations

### Units → Cyber Infrastructure

Players deploy cyber units instead of military armies:

| Unit | Purpose | Cost | Effect |
|------|---------|------|--------|
| **Proxy** | Traffic routing & obfuscation | 500 BW | +50 BW generation, 20 attack power |
| **Botnet** | Computational resource | 1500 BW | +100 compute, 60 DDoS power |
| **C2 Server** | Command & control | 3000 BW | +200 intelligence, 100 attack power |
| **Firewall** | Defense structure | 800 BW | 80 defense, 30% intercept chance |
| **Sinkhole** | Intelligence gathering | 600 BW | +150 intelligence, 40 defense |
| **Supercomputer** | High-power compute | 5000 BW | +500 compute, 80 attack power |
| **VPN Hub** | Privacy infrastructure | 2000 BW | +200 BW, 100 defense |

### Attacks → Cyber Operations

Instead of military attacks, players conduct **cyber attacks**:

- **DDoS (Distributed Denial of Service)** - Overwhelm target with traffic
- **Malware Deployment** - Persistent infiltration
- **Packet Injection** - Targeted data manipulation
- **Exfiltration** - Data theft for intelligence gathering
- **Resource Drain** - Siphon bandwidth/compute from target

Attack success depends on:
- Attacker's unit power
- Defender's firewall strength
- Network distance between datacenters
- Defender's active defenses

### Resources → Cyber Assets

Players manage three primary resources:

1. **Bandwidth (BW)** - Network throughput
   - Used to build units and launch attacks
   - Consumed by maintenance and special operations
   - Generated by datacenters and proxies

2. **Compute Power** - Processing capacity
   - Powers botnet operations
   - Enables complex attacks
   - Generated by botnets and supercomputers

3. **Intelligence** - Gathered data
   - Spent on espionage operations
   - Increases attack success rates
   - Generated by sinkholes and C2 servers

## Game Modes

### Classic (Adapted)
- **Free for All** - Last player with active infrastructure wins
- **Corporate Wars** - Teams represent mega-corporations
- **Nation State** - Team-based nation-state cyberwar
- **Hacker Collective** - Shifting alliances, anarchic gameplay

### New Cyber-Specific
- **Botnet Race** - First to 100K compute power wins
- **Intelligence Heist** - Gather 1M intelligence points first
- **Infrastructure Sabotage** - Destroy all enemy datacenters
- **Network Takeover** - Control 60% of network nodes

## Gameplay Loop

### Per-Tick Simulation

1. **Resource Generation**
   - Each datacenter generates bandwidth, compute, intelligence
   - Rate scales with datacenter tier and owned units

2. **Player Actions (Intents)**
   - Claim new datacenters
   - Deploy cyber units
   - Launch attacks
   - Form/break alliances
   - Share resources with allies

3. **Attack Resolution**
   - Active attacks progress each tick
   - Success calculated based on attacker vs defender strength
   - Results include damage, intelligence gathered, counter-attacks

4. **Datacenter Control**
   - Successful attacks can convert enemy datacenters
   - Requires sustained pressure or alliances
   - Abandoned datacenters return to neutral

5. **Maintenance**
   - Each unit costs bandwidth per tick to maintain
   - Network infrastructure degrades without upkeep

6. **Statistics Update**
   - Track player stats: datacenters, units, successful attacks
   - Calculate player rankings

## Alliance System

Players can form **cyber alliances** (botnets, hacking groups):

**Benefits:**
- Share bandwidth, compute, and intelligence pools
- Coordinated attack bonuses (+15% per allied attacker, up to 50%)
- Defensive synergy bonuses when defending together
- Shared resource generation

**Costs:**
- Resource commitment to maintain alliance
- Shared vulnerability if one member is compromised
- Limited alliance size (default: 4 players max)

## Map Generation

Network topology maps generated similarly to geographical maps:
- **Map Format**: Binary network graph
- **Nodes**: Datacenters with bandwidth/compute stats
- **Edges**: Network connections (latency affects attacks)
- **Tiers**: Edge, regional, core infrastructure
- **Regions**: Cloud zones, ISP hubs, DXs (Internet Exchanges)

## Client Rendering

Network visualizations instead of geographical:
- Datacenters as nodes on graph
- Attack traffic as animated flows
- Resource generation as particle effects
- Unit status as connected infrastructure

## Server Architecture

Same deterministic simulation model as OpenFront:
- **Client** runs deterministic core simulation
- **Server** coordinates intents, broadcasts turns
- **API** handles auth, stats, game records

## Balance Considerations

### Attack Balance
- Attacks cost significant resources
- Defense is affordable but not as powerful
- Lone players at disadvantage vs alliances
- Intelligence gathering adds tactical depth

### Resource Balance
- Bandwidth: primary currency (scarce initially)
- Compute: secondary, enables advanced attacks
- Intelligence: tertiary, enables espionage

### Datacenter Balance
- Early game: cluster around capitals
- Mid game: expansion to resource-rich regions
- Late game: contested network hubs

## Future Expansion

- **Zero-Day Exploits**: One-time powerful attacks
- **Firewall Updates**: Defender adaptation over time
- **Node Reputation**: Targeting high-value infrastructure
- **Botnet Lifecycle**: Units age, become less effective
- **Network Events**: Random disconnections, ISP outages
- **Ransomware Mode**: Extort opponents for resources
- **Honeypot Warfare**: Decoys to trap attackers
